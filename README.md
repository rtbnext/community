# RTBNext Community

Welcome to the official community repository for **RTBNext**.

This repository is the central place for everything related to the project outside of the source code.

## What belongs here?

- Bug reports
- Feature requests
- Questions and discussions
- Documentation feedback
- Reports about incorrect or outdated data

## Before opening an issue

Please check whether a similar issue already exists.

When reporting a problem, include as much relevant information as possible, for example:

- affected endpoint or page
- request URL
- expected behavior
- actual behavior
- error messages
- reproduction steps
